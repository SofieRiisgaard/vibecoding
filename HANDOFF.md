## What this is
A simple static personal site about Sofie — baking, nature, and photography. Plain HTML, CSS, and JavaScript. No build step and no dependencies. The site is in American English, with a soft Barbie-inspired pink look (see `agent.md` for the original brief).

## Where things live
- `index.html` — page content and structure
- `style.css` — colors, layout, responsive design
- `js/script.js` — sticky header, mobile menu, scroll reveal, gallery lightbox
- `images/` — original photos (untouched)
- `images/web/` — optimized copies actually used by the site
- `agent.md` — project brief
- `README.md` — original notes
